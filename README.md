# Personal Portfolio

Welcome to my personal portfolio! This repository contains the source code for my portfolio website, where I showcase my projects, skills, and experience.

## Live Demo

You can view the live version of my portfolio here: **[https://abhijeet1815.github.io/Personal_Portfolio/](https://abhijeet1815.github.io/Personal_Portfolio/)**

*(Note: The link will be active once GitHub Pages is enabled in the repository settings.)*

## Technologies Used

* **HTML5:** For structuring the content and layout.
* **CSS3:** For styling, responsive design, and animations.
* **JavaScript:** For interactive elements and dynamic functionality.

## Local Setup

To run this project locally on your machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/Abhijeet1815/Personal_Portfolio.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Personal_Portfolio
   ```
3. Open `index.html` in your web browser.
